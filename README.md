# Tổ 1 — Bảng Tuần Hoàn & Hóa Học Tương Tác

## Chạy nhanh trên Windows

Không cần cài Node.js hay nhập khóa API:

1. Mở thư mục `thử nghiệm 2`.
2. Nhấp đúp vào `To1-BangTuanHoan.html`.
3. Trong trình duyệt, bấm **Bắt đầu** để sử dụng chương trình.

File HTML này chạy trực tiếp trong trình duyệt. Cần có kết nối Internet để tải phông chữ; các công cụ hóa học chính không cần khóa Gemini.

## Chạy chế độ phát triển

Nếu muốn chỉnh sửa mã nguồn React/Vite, cài Node.js (phiên bản LTS), mở Terminal tại thư mục dự án rồi chạy:

```powershell
npm install
npm run dev
```

Mở địa chỉ mà Vite hiển thị trong Terminal (thường là `http://localhost:3000`).

Để kiểm tra mã TypeScript hoặc tạo bản build:

```powershell
npm run lint
npm run build
```
